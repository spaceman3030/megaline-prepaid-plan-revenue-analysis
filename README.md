Revenue Analysis of Telecom Prepaid Plans – Megaline Customer Behavior Analysis

Conducted a data analysis project focused on evaluating customer behavior and revenue generation across two prepaid telecom plans, Surf and Ultimate. Analyzed usage patterns from a sample of 500 telecom customers to determine which service plan generated higher revenue and provide data-driven insights to support marketing and advertising budget decisions.

Performed data cleaning, aggregation, and exploratory analysis using customer call activity, text messaging behavior, plan subscriptions, and regional information to identify trends and differences in customer usage.

Key responsibilities included:
• Data preprocessing and quality validation
• Customer behavior analysis
• Revenue analysis and comparison between service plans
• Exploratory Data Analysis (EDA)
• Statistical analysis and hypothesis testing
• Data visualization and insight communication
• Business-focused recommendation development

Tools & Technologies: Python, Pandas, Matplotlib, Statistical Analysis, Exploratory Data Analysis (EDA), Jupyter Notebook

This project strengthened my ability to analyze customer usage data, evaluate business performance metrics, and translate analytical findings into actionable business recommendations.
